# 16: Spatial Social Network

16 is a spatial social networking platform that visualizes user connections on an interactive, graph-based map.

## Core Features
- **Spatial Visualization:** Uses `react-force-graph` to render a dynamic, interactive network map of users.
- **Authentication:** Phone number-based login and registration using one-time passcodes (OTP).
- **Invite-Only Access:** Exclusivity-focused registration.
- **Social Interaction:** Features for discovering, tagging, connecting with, and managing relationships with other users.

## Tech Stack
- **Frontend:** React, TypeScript, `react-force-graph` for graph visualization.
- **Backend:** Java (Spring Boot), PostgreSQL, JPA/Hibernate.
- **Infrastructure:** Docker/Docker Compose.

## Testing
- **Backend:** JUnit 5, Mockito, Spring Boot Test.
- **Frontend:** Currently no automated testing framework configured.
